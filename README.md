## 👨‍💻 Sobre mim

Olá! Sou **Guilherme Ferreira**, estudante de **Análise e Desenvolvimento de Sistemas na FATEC Araçatuba**, atualmente no 4º semestre.

Tenho foco em **desenvolvimento back-end** e interesse em construir aplicações, trabalhar com banco de dados e aprender boas práticas de desenvolvimento.

Atualmente, estou aprofundando meus conhecimentos em **Java, Python e MySQL**. Também desenvolvo projetos acadêmicos e pessoais utilizando outras tecnologias.

- 🎓 Análise e Desenvolvimento de Sistemas — FATEC Araçatuba
- 💻 Foco atual: desenvolvimento back-end
- 📚 Estudando: Java, Python, MySQL e orientação a objetos
- 🔐 Interesse adicional: cibersegurança
- 🚀 Objetivo: evoluir por meio de projetos práticos e desafios reais
